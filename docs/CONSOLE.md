# 统一控制台

从任意目录运行项目根目录的 `start_pendulum.ps1`。它会先增量编译，再启动唯一的 `pendulum_console` 程序。构建信息写入 `out/launcher-build.log`。

- 输入 `1` 并回车：一级自动回中、确认下垂零点、起摆并切换到稳定控制。
- 输入 `2` 并回车：二级自动回中、确认两个下垂零点、三阶段起摆并切换到稳定控制。
- 运行中按 `Q` 或 `Esc`：停止输出并返回选择界面；选择界面输入 `Q` 回车退出。
- `Ctrl+C`：保留原有进程急停。

模式在初始化硬件之前确定。停止后释放当前采集任务，再选择下一个模式；一级不打开第二摆编码器。每次新会话重新执行回中和零点检查，不跨会话复用位置。

界面只显示当前模式、运行阶段、停止提示和必要错误。编码器计数、控制器中间量、回中过程及运行统计继续写日志，不在操作界面展开。日志位置由配置中的 `logging.directory` 指定。

开发验证可用 `pendulum_console --validate-only` 检查两种配置，或用 `--preview` 查看同一界面；这两个模式不打开硬件。正常启动脚本不启用它们。
