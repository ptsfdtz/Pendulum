# 引脚定义

| 功能 | PCI-6602 通道 | Pin |
| --- | --- | ---: |
| 小车编码器 A | CTR0 SOURCE | **2** |
| 小车编码器 B | CTR0 AUX | **40** |
| 一级摆编码器 A | CTR1 SOURCE | **7** |
| 一级摆编码器 B | CTR1 AUX | **6** |
| 二级摆编码器 A（黑） | CTR2 SOURCE | **34** |
| 二级摆编码器 B（白） | CTR2 AUX | **66** |
| 二级摆编码器 Z（橙，可选） | CTR2 GATE | **67** |
| 二级摆编码器 0 V（蓝） | D GND | **33 / 68** |
| 二级摆编码器 +5 V（棕） | +5 V | **1** |
| 左限位 | `port0/line0` | **10** |
| 右限位 | `port0/line2` | **45** |
| Servo ON | `port0/line3` | **12** |
| Servo ON GND | D GND | **11** |
| 电机控制 | PCI-1723 AO0 | AO0 |

二级摆编码器采用 X4 解码：1000 pulses/rev，最终 4000 counts/rev。
CTR2 默认 A/B 路由即 pin 34 / pin 66；Z 相目前不参与控制。
