# Simulink 算法验证接口

两份模型顶层均为左侧 `Hardware`、右侧 `Control`。替换 `Control` 内部即可接入自己的算法。唯一输出是加速度，没有复位、阶段或电压的隐藏反馈通道。

| Hardware → Control | 定义 |
| --- | --- |
| Angle1_deg | 第一杆绝对角，直立为 0°，约 [-180°,180°]，沿用原编码器符号 |
| Angle2_deg | 第二杆绝对角，已完成相对关节角转换；一级模型固定为 0 |
| Position_m | 本次回中为 0，向右为正、向左为负，单位 m |
| Limits_left_right | 两元素向量 [左,右]；1 已触发、0 未触发 |
| Servo | 启动流程自动控制的使能命令状态；0 关闭、1 开启，并非驱动器独立反馈 |
| Control → Hardware: Acceleration_m_s2 | 标量加速度，单位 m/s²，正方向与位置一致 |

`Control` 内保留度转弧度、速度估计、一级能量起摆/LQR、二级三阶段起摆/LQR及跌落回退。一级周期 0.01 s，二级 0.005 s；二级速度估计使用 20 Hz 滤波。角度跨圈时，一级能量计算使用包裹后的相邻角度差，避免将 ±180° 跳变当作整圈运动。

`Hardware` 负责设备读写、回中标零、编码器转换，以及加速度积分→速度参考→PI→电压输出。一级/二级加速度限制分别为 ±10/±30 m/s²，速度参考 ±0.6 m/s，电压 ±1 V。一级保留原 0.005 积分系数；二级保留静止电压补偿和抗饱和。物理限位、位置越界和非有限命令由硬件层独立检查，即使替换算法忽略限位也会关闭输出。

使能前传感器与算法可以更新，但电压保持 0，电压环积分器复位。启动流程完成预热、回中、标零与输入复核后自动使能；下一个采样将 Servo=1 交给算法。控制阶段任一物理限位触发即停机，Stop/异常退出清零电压并关闭伺服。

## 与旧模型的差异

旧版二级从稳摆跌落时会直接复位电压环的速度参考和 PI 积分。为了让任意算法只输出一个加速度，新版取消该阶段耦合；抗饱和、软限位复位、未使能和故障复位仍保留。因此加速度控制律可以离线对照，跌落后的电压轨迹不承诺与旧版完全一致，需要后续实机验证。

内置算法将阶段单独记录到仿真结果 `pn_stage`，仅作本地日志，硬件不读取它。硬件 `samples.csv` 保留原字段布局，其中 `stage` 固定为 0；运行结果标记 `interface_version=2`，不再据硬件日志自动断言已完成全部起摆阶段。

## 使用与验证

在项目根目录的 MATLAB 中运行：

```matlab
start_pendulum_simulink(1) % 一级实机
start_pendulum_simulink(2) % 二级实机
start_pendulum_simulink(2,'readonly',5) % 只读预检，不打开输出
```

也可直接打开模型点击 Run，由启动流程自动使能；Stop 关闭输出。

```matlab
addpath('matlab/native_simulink');
pn_verify();           % 不重建；已保存模型的离线接口、算法回归、电压环与保护检查
pn_export_diagrams(); % 输出模型、算法层和硬件层图片
pn_build();            % 明确覆盖两份模型，恢复内置算法
```

`pn_verify` 不打开真实设备，测试时将设备模块替换为数据源。自定义算法通常不满足内置算法数值断言，应按自己的算法建立效果测试；硬件接口及保护逻辑应保持不变。本次重构只做离线验证，未运行实机。

2026-09-09 离线验证：两模型编译通过；每阶 2400 点主回归覆盖全部控制阶段。跨 ±180°、独立电压环递推、使能切换、左右/同时限位、越界、超大加速度、NaN/Inf 命令检查通过。模拟设备的实际 S-function 启动、输入复核、超时和停止清零测试通过。结果保存在 `matlab/output/native_simulink/interface_verification.mat` 和 `startup_verification.mat`；这些检查不等同于实机起摆验收。
